PRODUCTION ARCHITECTURE GUIDE

Turning This Scrollytelling Experience into a Full Web App

Follow these actionable steps to turn this single-page interactive experience into a scalable, hosted production app.

STEP 1: Free Hosting & Instant Deployment Vercel / Netlify / GitHub Pages

1. Save this file as index.html.
2. Push the repository to GitHub.
3. Connect the repo to Vercel or Netlify for instant free global CDN hosting with automatic SSL HTTPS.

STEP 2: Protecting Gemini API Keys via Serverless Functions Node.js / Vercel API Route

To avoid exposing your Gemini API key on the frontend, create a lightweight serverless endpoint: 

// api/gemini.js (Vercel Serverless Function)
export default async function handler(req, res) {
  const { prompt } = req.body;
  const apiKey = process.env.GEMINI_API_KEY; // Stored securely in environment variables
  
  const response = await fetch(`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${apiKey}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ contents: [{ parts: [{ text: prompt }] }] })
  });
  
  const data = await response.json();
  res.status(200).json(data);
}
